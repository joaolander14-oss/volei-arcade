# Vôlei Arcade

Vôlei 2D de vista de cima, estilo arcade: a bola cresce quanto mais alta e a sombra marca onde ela está no chão.

- De 1 a 6 jogadores por equipe, com **rodízio** de posições (3 a 6 jogadores).
- Golpes: pochete, levantada, largada, cortada, bloqueio, mergulho e três tipos de saque.
- Modos: 1 jogador contra o computador (3 dificuldades), 2 jogadores no mesmo teclado e **online** (sala com código, via PeerJS).
- Controles principais no teclado numérico: Num 8/4/5/6 mover, Num 1 pochete, Num 2 levantada, Num 3 cortada, Num 0 pular/bloquear, Num . mergulho.

É só abrir `index.html` (ou servir a pasta com qualquer servidor estático). O modo online precisa de internet para a troca de códigos de sala.
